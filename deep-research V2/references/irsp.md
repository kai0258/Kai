1|# 信息源筛查协议（IRSP）
     2|# Information Resource Screening Protocol
     3|
     4|## 触发条件
     5|
     6|当研究对象涉及以下领域时，**必须**执行本协议：
     7|- 政治人物、政治运动、政治制度
     8|- 历史事件（尤其是20世纪以来的争议性历史）
     9|- 意识形态（女权主义、民族主义、宗教原教旨主义等）
    10|- 地缘政治冲突
    11|- 涉及信息管控严格国家和地区的议题
    12|
    13|当研究对象不涉及上述领域时，本协议为建议性参考。
    14|
    15|## 核心铁律
    16|
    17|**受污染的信息源一律排除，无例外。**
    18|
    19|具体规则：
    20|1. 明确受政权控制的宣传机构（如RT、塔斯社、朝中社等各国官方宣传机构）**一律排除**，不作为任何关键事实的来源。用户可根据所在地区自行补充本地受控媒体名单
    21|2. 英文学术来源和主流英文媒体来源**优先于**中文来源
    22|3. 如无法确定某个信息源的受污染程度，**排除该信息源**
    23|4. 学术来源优先于媒体来源，媒体来源优先于博客/社交媒体
    24|5. 对于任何来源，都要问：「这个来源有没有动机扭曲事实？」
    25|
    26|## 可信度分级
    27|
    28|对搜索到的每个来源进行分级：
    29|
    30|### A级（高度可信）
    31|- 顶级同行评审学术期刊（Nature, Science, Lancet, 各学科顶刊）
    32|- 权威百科全书（Encyclopedia Britannica, Stanford Encyclopedia of Philosophy）
    33|- 官方一手文件（法律文本、政府公报、公司SEC文件）
    34|- 国际组织官方报告（UN, WHO, World Bank, OECD）
    35|- 知名大学的学术出版物
    36|
    37|### B级（可靠）
    38|- 主流英文媒体的原创报道（NYT, BBC, Guardian, Reuters, AP, FT, Economist）
    39|- 知名智库报告（Brookings, RAND, CFR, Chatham House）
    40|- 主流中文媒体的非政治性报道（财经、科技领域可适度参考）
    41|- 学术预印本（arXiv, SSRN, bioRxiv — 需注意未经同行评审）
    42|- 权威行业分析（Gartner, McKinsey — 需注意利益冲突）
    43|
    44|### C级（需谨慎）
    45|- 博客、个人网站、Medium文章
    46|- 社交媒体帖子（Twitter/X, Reddit, 知乎）
    47|- 三级来源 / 百科类来源（Wikipedia、Britannica、百度百科等 — 详见「Encyclopedia & Tertiary Sources Policy」）
    48|- 二手转载/聚合报道（需追溯到原创来源）
    49|- 中文自媒体（公众号、知乎专栏 — 除技术领域外普遍不可靠）
    50|
    51|### D级（排除）
    52|- 明确的宣传机构
    53|- 匿名来源且无法交叉验证
    54|- 已知传播虚假信息的平台或账号
    55|- 利益冲突明显且未披露的来源（如公司自评报告当独立来源用）
    56|
    57|## 执行流程
    58|
    59|### 第一步：来源标注
    60|
    61|信息采集阶段，对每个搜索结果标注来源等级。格式示例：
    62|```
    63|[事实描述]（据NYT报道 [B级] / 据Crenshaw 1989 [A级]）
    64|```
    65|
    66|### 第二步：来源审计
    67|
    68|信息审计阶段，统计所有关键事实的来源分布：
    69|- A+B级占比是否 > 60%？（红线）
    70|- 是否有关键事实仅靠C级来源支撑？（需补搜或标注不确定性）
    71|- 是否有关键事实仅靠单一来源支撑？（需交叉验证）
    72|
    73|### 第三步：可靠性报告
    74|
    75|输出可靠性风险清单（内部文档）：
    76|```
    77|1. [事实描述] — 来源: [仅X级来源] — 风险: [高/中/低] — 处理: [补搜/标注/排除]
    78|2. ...
    79|```

    81|## 常见误判
    82|
    83|**误判1**：「Wikipedia是不可靠来源」
    84|→ 维基百科是优秀的线索发现工具，但关键事实必须回溯到维基百科引用的原始来源。
    85|
    86|**误判2**：「学术论文一定是可靠的」
    87|→ 需要考虑：是否来自掠夺性期刊？是否已被撤稿？作者是否有利益冲突？预印本未经同行评审。
    88|
    89|**误判3**：「英文来源就一定中立」
    90|→ 英文媒体也有立场倾向（如Fox News偏右，Guardian偏左）。但相对于受政权控制的媒体，其多元性和纠错机制更强。
    91|
    92|**误判4**：「排除了受污染来源就一定能得到真相」
    93|→ 不一定。西方学术界和媒体对某些议题也可能存在盲区和偏见。IRSP的目标不是保证绝对真理，而是**最小化已知的信息污染风险**。
    94|
    95|## 例外情况
    96|
    97|当研究对象本身就是受污染信息源的产物（如研究「某国官方媒体的国际报道策略」），当然需要引用该来源——但引用的是「该来源说了什么」，而非「该来源说的就是事实」。这种情况下，需要额外的独立来源来交叉验证。

## Encyclopedia & Tertiary Sources Policy（三级来源规范）

### 定义

三级来源（Tertiary Sources）指以**汇总、整理、归纳、转述他人信息为主**的知识载体，分为两类：

**编辑审校型百科（Editorially Reviewed Encyclopedias）**：
- Wikipedia（有编辑审核机制和引用规范）
- Britannica、Scholarpedia、Stanford Encyclopedia of Philosophy
- 百度百科、互动百科（审核机制较弱，但有基本编辑流程）

**社区维护型 Wiki（Community-Maintained Wikis）**：
- Fandom、游戏 Wiki、角色 Wiki、粉丝 Wiki
- 社区知识库、其他用户共建型知识站

**其他三级来源**：
- 行业知识库、协作型词条站
- 以二次整理为主的手册、指南、概览

> Community-maintained wikis should generally be treated as lower-confidence tertiary sources than editorially reviewed encyclopedias. 在关键事实判断上，社区 Wiki 的可信度应低于编辑审校型百科。

### 允许用途

三级来源可用于：

- **术语发现**：快速了解研究对象的基本概念和术语体系
- **实体识别**：找到关键人物、事件、组织、机构
- **时间线梳理**：获取事件的大致顺序和时间节点
- **参考文献发现**：追踪条目底部引用的原始来源
- **关系网络初步建模**：理解实体之间的关联
- **研究入口导航**：确定后续深入搜索的方向和关键词

### 限制

三级来源**不得作为**以下判断的唯一依据：

- 数字结论（统计、排名、金额、比例）
- 争议性判断（政治立场、责任归属、因果关系）
- 因果判断（X导致了Y）
- 责任认定（谁做了什么、谁应负责）
- 高风险结论（影响报告核心论点的判断）

### 使用流程

正确的使用路径：

```
三级来源 → 发现线索 → 追溯原始来源 → 形成结论
```

错误的使用路径：

```
三级来源 → 直接形成结论 ✗
```

### Reasonable Verification Principle（合理验证原则）

研究者应**尽合理努力**寻找更高质量来源，但不必无限追溯：

- 如果经过合理检索（至少一轮针对性搜索）后仍找不到更高质量来源，**可以使用三级来源**
- 但必须**降低置信度**，并**明确说明限制**（如「该信息仅见于XX百科，未找到独立来源确认」）
- 合理努力的标准：用至少两组不同关键词搜索，检查三级来源底部的参考文献列表并尝试追溯
- 超出合理努力范围后，不必继续追溯——避免无限搜索导致研究瘫痪

### Citation Chain Check（引用链审查）

「有引用」不等于「可靠」。必须检查引用链末端的**最终来源质量**：

- 不能因为一个说法「有来源」就默认可靠
- 必须追踪引用链到底：Wikipedia → 博客 → 博客 → 论坛 = 表面有来源，实际证据链很弱
- 如果引用链末端是另一个三级来源、社区帖子或匿名来源，则该引用链**不构成有效证据**

**Citation Laundering 警示**：

```
✗ 错误：Wikipedia 引用博客 → 博客引用博客 → 博客引用论坛 → "有来源"
✓ 正确：Wikipedia → 追溯底部引用 → 找到期刊论文/官方记录 → 有效来源
```

在审计阶段，对每个关键事实的引用链进行末端检查。如果末端来源质量低于C级，则该引用链不计入有效来源支撑。

### 审计项：Tertiary Source Dependency Check

在信息审计阶段（阶段三），增加以下检查：

| 检查项 | 标准 |
|--------|------|
| 关键结论是否只依赖三级来源？ | 不允许 |
| 是否已追溯到更高质量来源？ | 必须 |
| 三级来源是否仅作为导航源？ | 必须 |

**处理规则**：
- 如果关键结论只依赖三级来源 → **降低置信度**，标注为「待补强」
- 如果有更强来源可追溯但未追溯 → **要求补搜**
- 如果三级来源是某判断的唯一支撑 → **回退该判断**，改为「该信息暂缺，现有线索指向…（据XX百科）」


## Conflicting Evidence Protocol（来源冲突处理）
   100|
   101|When high-quality sources disagree:
   102|
   103|- Do not force reconciliation — do not pretend agreement exists when it doesn't
   104|- Present competing interpretations side by side
   105|- Explain evidentiary strengths of each position
   106|- Identify unresolved uncertainty
   107|
   108|Uncertainty should be reported rather than hidden.
   109|
   110|When sources conflict, the report should:
   111|1. State what each source claims
   112|2. Assess the relative credibility of each source
   113|3. Explain why the disagreement exists (if known)
   114|4. Indicate which interpretation has stronger evidentiary support, or explicitly state that the matter is unresolved
