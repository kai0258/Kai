# 研究报告质量审查清单

## 审查范围

对存档目录中的研究报告执行批量审查时，按以下四层逐项检查。

---

## Layer 1: 版本一致性检查

检测报告是否使用了正确的 skill 模板。

| 检查项 | 新版特征 | 旧版特征 |
|--------|----------|----------|
| 报告头部 | `Research Date: YYYY-MM-DD` | `研究时间：YYYY年M月D日` |
| Core Findings | 有（报告开头3-5条摘要） | 无 |
| Scope and Boundaries | 有 | 无 |
| 存档路径 | 固定路径，不询问用户 | 主动询问用户存档位置 |
| 输出格式 | 默认 Markdown | 默认 PDF |

自动检测方法：检查前30行是否包含 `Core Findings` + `Research Date`。

---

## Layer 2: 信息源铁律合规检查

### 2a. 来源章节检查

扫描 `## 五、信息来源` 或 `## 信息来源` 章节，检查是否包含以下违规来源：

```
[用户自定义的受控媒体名单]
示例：RT、塔斯社、朝中社等各国官方宣传机构
提示：将本地受控媒体域名和名称加入此列表
```

### 2b. 正文行内引用检查

扫描正文中的 `据XXX记载/研究/指出/报道` 模式，区分：

- **历史提及**（可接受）：「某媒体发表了社论...」— 描述历史事实
- **作为信源引用**（违规）：「据某受控媒体报道...」— 把宣传机构当信源

### 2c. "排除说明"特殊处理

报告中常出现"本报告排除了XX、YY、ZZ等..."的排除声明。这类声明中提及的媒体名称**不是信源引用**，应跳过不计。

判断方法：行中包含"排除"二字 → 跳过该行的检测。


---

## Layer 3: 模糊引用检查

检查 `据XXX记载/研究/指出` 中的 XXX 是否为具体可追溯来源。

### 需要标记的模糊模式

| 模式 | 问题 | 修正要求 |
|------|------|----------|
| 据华艺线上图书馆 | 平台名，非原始来源 | 补全期刊名、作者、年份 |
| 据知网 / 据CNKI | 同上 | 同上 |
| 据爱思想 | 同上 | 同上 |
| 据Wikipedia / 据维基百科 | 三级来源当主信源 | 追溯到 Wikipedia 底部的原始引用 |
| 据历史学家 / 据多位学者 | 无具体人名 | 补全学者姓名和出处 |
| 据媒体 / 据报道 | 完全模糊 | 补全具体媒体名和文章标题 |
| 据[受控机构]的研究 | 受控来源 | 排除或替换为独立来源 |

### 可接受的模式

| 模式 | 原因 |
|------|------|
| 据XXX（1998）/ 据XXX et al. | 有学者名+年份，可追溯 |
| 据《XX期刊》/ 据XX University Press | 有具体期刊/出版社 |
| 据FRUS / 据Peking Spring档案 | 有具体档案名 |
| 据英国议会官方网站 | 官方档案网站 |

---

## Layer 4: 三级来源依赖检查（Tertiary Source Dependency Check）

针对每个关键结论，检查其证据来源：

- 是否只依赖三级来源（Wikipedia、百科、社区Wiki）？
- 是否已追溯到更高质量来源？
- 引用链末端是否为有效来源（Citation Chain Check）？

### 分级

| 三级来源类型 | 可信度 | 说明 |
|-------------|--------|------|
| 编辑审校型百科（Wikipedia、Britannica、SEP） | 中 | 可作导航，不可作主信源 |
| 社区维护型 Wiki（Fandom、游戏Wiki） | 低 | 仅限术语发现和实体识别 |

---

## 审查输出格式

```
📄 [报告名]
├─ Layer 1 版本: ✓ 新版 / ✗ 旧版
├─ Layer 2 来源: ✓ 无违规 / ✗ N处违规（列出）
├─ Layer 3 模糊: ✓ 无 / ✗ N处（列出类型）
└─ Layer 4 三级: ✓ 无过度依赖 / ✗ N处（列出）
```

---

## 严重程度分类

| 等级 | 标准 | 处理 |
|------|------|------|
| 🔴 严重 | Wikipedia当主信源 / 受控来源当信源 | 重写 |
| 🟡 中等 | 模糊引用（平台名/机构名代替原始来源） | 补全出处 |
| 🟢 合格 | 小问题（个别引用格式不规范） | 标注修正 |
