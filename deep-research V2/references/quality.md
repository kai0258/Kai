# 质检评分矩阵详细标准

## 评分总览

满分100分，90分及格。最多补强2轮。

## 否决机制

**硬否决（直接不交付，必须重写）**：
- 编造信息（搜不到就编、伪造来源、捏造数据）
- 教科书开头（"在当今AI快速发展的时代"等）

**软否决（触发后该项自动失败，必须修改后重新评分）**：
- 出现2处以上套话
- 出现2处以上高频踩雷词
- 出现空洞形容词

A soft veto means:
- the criterion automatically fails
- the affected section must be revised
- rescoring is mandatory after revision

There is no "pass with conditions" — a soft veto always blocks delivery until resolved.

硬否决优先于总分：即使其他项目满分，触发硬否决仍不交付。

## 逐项评分标准

每项均附 90/75/60 三档锚点，用于标准化打分。

### 1. 纵轴叙事质量（15分）

**满分标准**：
- 读者能感受到「为什么一步一步走到了今天」
- 有因果逻辑，不是年表流水账
- 句子长短交替，段落之间跳跃自然
- 有起承转合的叙事弧线

**常见扣分**：
- -3分：写成了大事记列表（「1990年发生了X，1991年发生了Y」）
- -3分：缺乏因果连接（只说「发生了什么」，不说「为什么」）
- -2分：叙事节奏单调（每段一样长，没有轻重缓急）
- -2分：缺少时代背景铺垫（读者不知道某个事件为什么在那个时候发生）

**评分锚点**：
- 90 = 完整叙事故事体，有因果链、节奏起伏、时代脉络，读起来像非虚构写作
- 75 = 整体叙事体但有1-2处退化为罗列/流水账
- 60 = 大段年表式罗列，叙事感薄弱

### 2. 关键节点展开度（10分）

**满分标准**：
- 每个关键节点至少包含：事件描述 + 背景/原因 + 决策过程 + 结果/影响
- 重要细节不遗漏，不为压缩而跳过

**常见扣分**：
- -2分/节点：某个重要节点一笔带过
- -1分/节点：节点只有事件描述，缺乏背景和原因

**评分锚点**：
- 90 = 每个关键节点有独立小节，包含决策逻辑还原和多方史料支撑，无信息断层
- 75 = 主要节点展开但有1-2处压缩为概述；或存在明显信息断层（如某10年历史完全没有覆盖）
- 60 = 多处蜻蜓点水，仅有事件罗列而无深入分析

### 3. 决策逻辑还原（10分）

**满分标准**：
- 不只说「他们做了X」，还说「当时面对什么约束条件，为什么选了X而不是Y」
- 有路径依赖分析：哪些早期决策锁定了后来的方向
- 有「错过的岔路口」：哪些关键时刻本可以走另一条路

**常见扣分**：
- -3分：完全没有决策逻辑，只有事件罗列
- -2分：有决策逻辑但过于简化（「他们选了X因为X更好」）

**评分锚点**：
- 90 = 不只记录"发生了什么"，还还原了"为什么这么选"；对学界无定论的问题标注了「尚有争议」或「暂无定论」
- 75 = 主要决策有逻辑还原但有1-2处缺失；或未对学界争议点做标注
- 60 = 大量事件仅有结果而无决策过程还原；或对争议问题武断下结论

### 4. 横轴场景判断（5分）

**满分标准**：
- 正确判断场景A（无直接竞品）/ B（少量竞品）/ C（竞品充分）
- 场景判断有理有据

**常见扣分**：
- -3分：场景判断错误（明明有竞品却说没有，或反之）
- -2分：场景判断没有理由

**评分锚点**：
- 90 = 场景判断正确且有充分论据，逻辑自洽
- 75 = 场景判断正确但论据不够充分
- 60 = 场景判断错误

### 5. 横轴分析深度（15分）

**满分标准**：
- 场景C：每个主要对比方至少1500字独立分析
- 有核心差异对比、用户视角/口碑、生态位分析、趋势判断
- 维度对比矩阵覆盖最关键的对比维度

**常见扣分**：
- -3分/对比方：某个对比方分析不到1000字
- -2分：对比维度选择不合理（选了不重要的维度）
- -2分：只有官方宣传，没有用户视角/批评声音

**评分锚点**：
- 90 = 每个主要对比对象有1500字以上独立分析，维度全面，引用真实多方声音
- 75 = 个别对比对象分析偏薄，或遗漏1个主要对比对象
- 60 = 对比浮于表面，像参数对照表而非活的分析

### 6. 横纵交汇原创性（10分）

**满分标准**：
- 产出前文没有的新判断
- 不是前面内容的缩写版
- 有「文化升维」——连接到更大的历史/哲学参照

**常见扣分**：
- -5分：交汇部分只是把前面的内容换了个说法重写一遍
- -3分：有新判断但缺乏深度，浮于表面
- -2分：缺乏文化升维或历史参照

**评分锚点**：
- 90 = 产出了新的综合性判断，历史脉络和竞争格局真正交叉出了新观点，有文化升维
- 75 = 有交汇但洞察深度不够，部分段落退化为前文摘要
- 60 = 基本是前面内容的重新排列，没有新判断

### 7. 未来推演逻辑（5分）

**满分标准**：
- 三个剧本（最可能/最危险/最乐观）各有逻辑支撑
- 推演基于前面的分析，不是凭空想象

**常见扣分**：
- -2分：某个剧本没有逻辑支撑
- -2分：三个剧本太相似，缺乏区分度

**评分锚点**：
- 90 = 三个剧本各有独立逻辑链，能追溯到纵向和横向分析中的具体论据
- 75 = 三个剧本有但逻辑链偏弱，或某个剧本流于空泛
- 60 = 推演缺乏逻辑支撑，像是随意编造的三种可能性

### 8. 信息来源质量（10分）

**满分标准**：
- A+B级来源占比 > 60%
- 每个关键事实有行内引用
- 来源多样性好（不依赖单一来源）

**常见扣分**：
- -3分：A+B级占比 < 60%
- -3分：大量关键事实没有行内引用
- -2分：过度依赖单一来源（超过30%的关键事实来自同一来源）

**评分锚点**：
- 90 = 所有关键事实有来源标注；引用的来源为一手来源或权威二手来源；来源覆盖了多方立场
- 75 = 大部分有来源但有1-2处遗漏；或有1-2处依赖了低质量二手聚合源
- 60 = 多处关键事实无来源；或大量依赖不可靠的二手源/聚合站

### 9. 信息平衡性（5分）

**满分标准**：
- 正面评价和负面评价/批评都有
- 没有回避显而易见的争议

**常见扣分**：
- -3分：只有一面之词（只有赞美或只有批评）
- -2分：有明显的「房间里的大象」被回避

**评分锚点**：
- 90 = 引用了真实多方声音，正反面评价都有覆盖，争议问题有标注
- 75 = 有用户声音但来源单一，或偏重一面之词
- 60 = 几乎全部依赖官方宣传或单一来源

### 10. 写作风格（5分）

**满分标准**：
- 有节奏感（句子长短交替）
- 叙事驱动（有故事弧线）
- 知识自然带出（不是「下面科普一下」）
- 敢下判断（用「我觉得」承认主观性）

**常见扣分**：
- -2分：风格像冷冰冰的咨询报告
- -2分：口语化过度（满篇「这玩意」「太牛逼了」）
- -1分：节奏单调

**评分锚点**：
- 90 = 节奏有起伏、叙事驱动而非罗列驱动、零禁区违规
- 75 = 整体可读但有1处禁区违规，或节奏偏平
- 60 = 出现2处以上禁区违规，或读起来像咨询报告/教科书

### 11. 无禁区违规（5分）

**检查清单**：
- □ 无「首先...其次...最后」「综上所述」等套话
- □ 无「赋能」「抓手」「打造闭环」等空洞词
- □ 无「在当今XX快速发展的时代」等教科书开头
- □ 无「说白了」「意味着什么？」「本质上」等高频踩雷词
- □ 无编造的信息（搜不到的标注了「暂缺」）

**扣分**：每发现一处 -1分，扣完为止。

**评分锚点**（含否决触发）：
- 90 = 零禁区违规
- 75 = 1处轻微禁区违规（如1处套话）
- 60 = 2处以上禁区违规 → 触发软否决（必须修改后重新评分）
- < 60 = 出现硬否决项（编造信息/教科书开头）→ 直接不交付

### 12. 篇幅达标（5分）

| 深度等级 | 目标字数 | 达标区间 |
|---------|---------|---------|
| L1 | 3000-5000 | 2500-6000 |
| L2 | 10000-15000 | 8000-18000 |
| L3 | 15000-30000 | 12000-35000 |

**扣分**：
- -2分：低于达标区间下限
- -3分：低于目标字数的50%
- -2分：超过达标区间上限（信息密度可能不足）

**评分锚点**（以L3为例）：
- 90 = 15,000-25,000字
- 75 = 12,000-15,000字或25,000-30,000字
- 60 = 10,000-12,000字或30,000-35,000字
- < 60 = 不足10,000字或超过35,000字

### 13. 关键事实可追溯性（Critical Fact Traceability）

**评分标准**：

| 分数 | 标准 |
|------|------|
| 5 | All critical facts traceable to specific sources |
| 4 | Minor omissions — a few facts lack explicit citation |
| 3 | Several unsupported claims identified |
| 2 | Many unsupported claims; evidence chain is weak |
| 1 | Critical conclusions lack any evidence; report is unreliable |

**判定依据**：按 Critical Fact Definition 中定义的范围，逐条检查所有关键事实是否有可追溯的来源标注。

## Improvement Cycle（补强闭环流程）

```
Initial Evaluation
        ↓
   If score < 90
        ↓
One remediation pass (target lowest-scoring items)
        ↓
Re-evaluation
        ↓
If still below threshold
        ↓
Produce remediation plan (list each deduction, proposed fix, expected improvement)
        ↓
Pause further improvement — submit plan to user for review
        ↓
User approves → Execute second pass → Re-evaluate
```

上限：最多补强2轮。第一轮自动执行，第二轮需用户审核方案后执行。
