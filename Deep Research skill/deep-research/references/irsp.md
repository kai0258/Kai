# 信息源质量协议（IRQP）
# Information Resource Quality Protocol

## 触发条件

当研究对象涉及以下情况时，**建议**参考本协议：
- 信息来源复杂、多方利益交织的话题
- 存在争议性观点或对立立场的话题
- 需要高可信度来源支撑的关键事实
- 涉及历史事件、商业竞争、行业格局等需要交叉验证的领域

当研究对象为技术文档、产品功能等事实明确的话题时，本协议为可选参考。

## 核心铁律

**受污染的信息源一律排除，无例外。**

具体规则：
1. 明确受政权控制或受商业利益深度绑定的宣传机构来源**一律排除**，不作为任何关键事实的来源
2. 如无法确定某个信息源的受污染程度，**排除该信息源**
3. 学术来源优先于媒体来源，媒体来源优先于博客/社交媒体
4. 对于任何来源，都要问：「这个来源有没有动机扭曲事实？」
5. 同一事实至少需要两个独立来源交叉验证

## 可信度分级

对搜索到的每个来源进行分级：

### A级（高度可信）
- 顶级同行评审学术期刊（Nature, Science, Lancet, 各学科顶刊）
- 权威百科全书（Encyclopedia Britannica, Stanford Encyclopedia of Philosophy）
- 官方一手文件（法律文本、政府公报、公司SEC文件、工商注册信息）
- 国际组织官方报告（UN, WHO, World Bank, OECD）
- 知名大学的学术出版物

### B级（可靠）
- 主流媒体的原创报道（NYT, BBC, Guardian, Reuters, AP, FT, Economist, WSJ, 财新, 端传媒等）
- 知名智库报告（Brookings, RAND, CFR, Chatham House, Bruegel）
- 学术预印本（arXiv, SSRN, bioRxiv — 需注意未经同行评审）
- 权威行业分析（Gartner, McKinsey, CB Insights — 需注意利益冲突）
- 公司官方博客和技术文档（当引用的是技术事实而非公关话术时）

### C级（需谨慎）
- 博客、个人网站、Medium/Substack文章
- 社交媒体帖子（Twitter/X, Reddit, 知乎, Hacker News）
- 维基百科（可作为线索来源，但关键事实需回溯到原始来源）
- 二手转载/聚合报道（需追溯到原创来源）
- 自媒体（公众号、YouTube、播客 — 除技术领域外需谨慎）

### D级（排除）
- 明确的宣传机构
- 匿名来源且无法交叉验证
- 已知传播虚假信息的平台或账号
- 利益冲突明显且未披露的来源（如公司自评报告当独立来源用）
- 付费软文、赞助内容、品牌合作（未标注为广告的内容更危险）
- SEO驱动的内容农场（批量生产、缺乏署名、大量堆砌关键词）

## 多源印证规则

单一来源永远不够。以下情况需要额外警惕：

1. **循环印证**：A引用B，B引用C，C引用A → 表面有三个来源，实际只有最初的一个
2. **通稿分发**：同一新闻稿被多家媒体转载 → 只算一个来源
3. **匿名知情人士**：「据知情人士透露」→ 需至少两个独立媒体的匿名来源互相印证
4. **数据来源追溯**：看到一个统计数字，必须追溯到原始数据收集方，而非引用它的二手文章

## 时效性规则

1. 技术/产品类事实：超过6个月的信息需要验证是否仍然成立
2. 商业/财务数据：以最近一个季度或财年为准
3. 学术理论：经典理论可引用较旧来源，但争议性论点需引用近5年文献
4. 历史事件：优先引用近年学术研究（可能包含新解密档案），而非事件当时的报道

## 立场平衡规则

1. 对任何争议性话题，必须同时引用不同立场的来源
2. 如果所有找到的来源都指向同一方向，需要主动搜索反方观点
3. 标注来源的已知立场倾向（如媒体的编辑倾向、智库的政治光谱位置）
4. 当不同来源的事实陈述互相矛盾时，如实呈现分歧，而非自行选择「正确」版本

## 执行流程

### 第一步：来源标注

信息采集阶段，对每个搜索结果标注来源等级。格式示例：
```
[事实描述]（据NYT报道 [B级] / 据Crenshaw 1989 [A级]）
```

### 第二步：来源审计

信息审计阶段，统计所有关键事实的来源分布：
- A+B级占比是否 > 60%？（红线）
- 是否有关键事实仅靠C级来源支撑？（需补搜或标注不确定性）
- 是否有关键事实仅靠单一来源支撑？（需交叉验证）
- 是否存在循环印证或通稿分发？

### 第三步：可靠性报告

输出可靠性风险清单（内部文档）：
```
1. [事实描述] — 来源: [仅X级来源] — 风险: [高/中/低] — 处理: [补搜/标注/排除]
2. ...
```

## 常见误判

**误判1**：「Wikipedia是不可靠来源」
→ 维基百科是优秀的线索发现工具，但关键事实必须回溯到维基百科引用的原始来源。

**误判2**：「学术论文一定是可靠的」
→ 需要考虑：是否来自掠夺性期刊？是否已被撤稿？作者是否有利益冲突？预印本未经同行评审。

**误判3**：「排除了受污染来源就一定能得到真相」
→ 不一定。任何媒体和学术界都可能有盲区和偏见。本协议的目标不是保证绝对真理，而是**最小化已知的信息污染风险**。

**误判4**：「英文来源就一定中立」
→ 英文媒体也有立场倾向和商业利益。但相对于单一控制的信息环境，其多元性和纠错机制更强。

**误判5**：「一手来源就一定可靠」
→ 官方公告可能有公关目的，创始人的访谈可能有夸大成分。一手来源也需要交叉验证。

## 例外情况

当研究对象本身就是宣传机构的产物（如研究「某媒体的国际报道策略」），当然需要引用该来源——但引用的是「该来源说了什么」，而非「该来源说的就是事实」。这种情况下，需要额外的独立来源来交叉验证。
